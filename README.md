# ✊🖐️✌️ Rock Paper Scissors Game

An interactive and responsive web implementation of the classic **Rock Paper Scissors** game built using core front-end web technologies.

🔗 **Live Demo:** [rock-paper-scissors-opal-three-41.vercel.app](https://rock-paper-scissors-opal-three-41.vercel.app)

---

## 🚀 Features
* **Interactive Gameplay:** Play against the computer with real-time score updates.
* **Custom Assets:** Clean UI using custom image graphics for Rock, Paper, and Scissors options.
* **Responsive Layout:** Formatted to work smoothly on both desktop and mobile viewports.

---

## 🛠️ Tech Stack
* **HTML5:** Page structure and layout
* **CSS3:** Styling, layout positioning, and visual effects
* **JavaScript (ES6):** Game logic, computer selection randomization, and DOM manipulation
